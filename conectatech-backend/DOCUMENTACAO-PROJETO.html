ConectaTech API

Plataforma que conecta estudantes da UNP a vagas de estagio na regiao de Mossoro/RN

Projeto de Extensao Universitaria — Universidade Potiguar (UNP)

Versao 1.0.0 — Marco 2026

1. Visao Geral

O ConectaTech e uma API REST que agrega vagas de estagio de multiplas fontes (API Jooble, web scraping e cadastro manual) e disponibiliza para estudantes universitarios de Mossoro/RN. Os estudantes podem buscar, filtrar e selecionar vagas de interesse atraves de uma interface simples e segura.

5. Fontes de Vagas

5.1 Jooble API

O JoobleService faz requisicoes POST para a API do Jooble com palavras-chave e localizacao, parseia o JSON retornado e salva as vagas no banco de dados. Evita duplicatas verificando a URL.

5.2 Web Scraping (JSoup)

O ScraperService acessa sites configurados via seletores CSS, extrai titulo, empresa, descricao, localizacao e link das vagas. Pode rodar via cron (agendado) ou manualmente pelo admin.

5.3 Cadastro Manual

O administrador pode criar vagas manualmente via POST /api/admin/jobs. A fonte e automaticamente definida como ADMIN.

6. Fluxo de Autenticacao

1
Estudante se registra via POST /api/auth/register com nome, email, senha, curso e periodo
2
Sistema cria usuario com role STUDENT e senha criptografada com BCrypt
3
Estudante faz login via POST /api/auth/login e recebe um token JWT (valido por 24h)
4
Nas proximas requisicoes, envia o token no header Authorization: Bearer <token>
5
O JwtAuthFilter intercepta cada requisicao, valida o token e define o contexto de seguranca
6
O Spring Security verifica se o usuario tem permissao para acessar o endpoint solicitado

8. Seguranca

MecanismoImplementacao
AutenticacaoJWT (JSON Web Token) com HMAC-SHA384
Criptografia de senhaBCrypt via Spring Security
AutorizacaoRole-based (STUDENT e ADMIN)
CORSConfiguravel por profile (dev: *, prod: restrito)
CSRFDesabilitado (API stateless)
SessaoStateless (sem sessao no servidor)
Validade do token24 horas
Recuperacao de senhaToken UUID com expiracao de 1 hora

Observacao: O primeiro usuario ADMIN deve ser criado diretamente no banco de dados. Apos isso, um admin pode promover outros usuarios via PUT /api/admin/users/{id} enviando "role": "ADMIN".

9. Fluxo do Estudante

1
Registro — Cria conta com nome, email, senha, curso e periodo
2
Login — Autentica e recebe token JWT
3
Buscar vagas — Navega e filtra vagas por texto, localizacao ou fonte
4
Selecionar — Adiciona vagas de interesse a sua lista pessoal
5
Gerenciar — Consulta e remove vagas selecionadas quando necessario
6
Perfil — Atualiza dados pessoais (nome, curso, periodo)
